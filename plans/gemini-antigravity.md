# Следующий проект: Gemini / Antigravity под управлением Claude через MCP

Порядок (решение владельца 2026-10-20): после режима без окна для Codex (plans/headless-service.md).

## Цель
Отдельный проект — аналог Rundix для Antigravity (Gemini): Claude Code через MCP ставит задачи, выбирает модель и глубину размышления, ждёт без опроса, отвечает на вопросы агента, читает отчёты, закрывает вкладки; работа видна и сохраняется в истории; по возможности сразу с режимом без окна на общем каркасе.
