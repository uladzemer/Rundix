# Rundix mark

The mark is a pair of curly braces enclosing the letter R: `{R}`.

The dark, light and theme-aware SVGs share matching geometry. R is drawn as a path, so it does not depend on installed fonts. These assets contain no OpenAI blossom geometry.

- `../rundix-dark.svg`: blue mark for dark surfaces and the source for the 256×256 extension-list PNG.
- `../rundix-light.svg`: darker blue mark for light surfaces.
- `../icons/rundix.svg`: `currentColor` version for the chat, generated into `ui/icons.js` by `node build.cjs`.
- `../extension-icon.png`: transparent raster export of `rundix-dark.svg`.

The production assets are included under the project's MIT license. This documentation folder is excluded from the VSIX.
