# Icon sources

All SVG icons in this directory are original Rundix project geometry covered by the project MIT license. Action icons use simple geometric paths. The Rundix curly-brace/R mark is shared with the native tab and extension icon; see ../branding/README.md. No icons from the official OpenAI extension are included.

`ui/icons.js` is generated from these local SVG files by `build.cjs`.
